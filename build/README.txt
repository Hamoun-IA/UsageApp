Placez ici l'icône Windows de l'application : icon.ico (256x256 idéalement).

Tant qu'il n'existe pas, electron-builder utilisera l'icône Electron par défaut.
Vous pouvez en générer une à partir d'un PNG avec :
  https://www.icoconverter.com/   (ou via ImageMagick : convert icon.png -define icon:auto-resize=256,128,64,48,32,16 icon.ico)
